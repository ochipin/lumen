役立つページは、読者が知りたいことに答えています。すべての段落を読む人も、一つの情報だけを探しに来た人も、その答えを見つけやすい構成にしましょう。

## 伝えたいことから書き始める

背景を説明する前に、何のためのページなのかを伝えましょう。身近な言葉、短い具体例、移動先の内容が分かるリンクを使います。

{{< info >}}
ページには、**書式を整えた文章**、[関連する記事へのリンク](/ja/journal/small-experiments/)、リスト、具体例などを載せられます。それぞれの要素に役割を持たせましょう。
{{< /info >}}

### 内容が伝わる見出しを選ぶ

見出しは、その後の段落で何を伝えるかを示すものです。「追加情報」よりも「公開する前に」のほうが、読者は内容を想像しやすくなります。このページの目次も、見出しに沿って表示されます。

### 関連する内容をまとめる

段落を短く区切ると、一つずつ内容を説明しやすくなります。同じ役割を持つ項目がいくつかある場合は、リストにすると読みやすくなります。

- 読者が次にすることを説明する。
- 抽象的な考え方には具体例を添える。
- 根拠や詳しい説明は、それが支える内容の近くに置く。

## 情報の種類が分かるラベルを付ける

ラベルがあると、補足、注意点、提案などを見分けやすくなります。サイトのアクセントカラーが変わっても、ラベルの意味は変わりません。

{{< notice >}}
例を自分の状況に合わせるには、調整が必要な場合があります。手順を試す前に、前提となる条件を確認しましょう。
{{< /notice >}}

{{< important >}}
簡単には元に戻せない変更を試す前に、元のデータを保存しておきましょう。
{{< /important >}}

{{< tips >}}
下書きを声に出して読んでみましょう。つかえる箇所は、文を短くしたり、文同士のつながりを明確にしたりすると読みやすくなることがあります。
{{< /tips >}}

{{< note >}}
補足欄には、読者が後から読み返せる背景情報を置くと便利です。
{{< /note >}}

## 関連する二つの内容を並べる

{{< columns align="start" >}}
  {{< column >}}
  ### 役立つ最初の下書き

  問い、今の時点での答え、手元にある根拠を書き出しましょう。未完成でも具体的な例があれば、ほかの人が検討を始めるきっかけになります。
  {{< /column >}}
  {{< column >}}
  ### 役立つ見直し

  何が分かりやすいか、何が足りないか、読者は次に何をすればよいかを考えましょう。全体的な感想よりも、具体的な指摘のほうが改善に役立ちます。
  {{< /column >}}
{{< /columns >}}

最後に、内容に合った行動を案内しましょう。たとえば、[小さな実験を試す](/ja/journal/small-experiments/)ことや、[ページを公開する準備](/ja/guides/publishing/a-useful-release/)につなげられます。
