A useful page answers a real question. Its structure should make that answer easy to find, whether someone reads every paragraph or visits for a single detail.

## Begin with the point you want the reader to understand

Say what the page is for before introducing the background. Use familiar words, short examples, and links whose labels explain where they lead.

{{< info >}}
A page can contain **formatted text**, [links to related reading](/journal/small-experiments/), lists, and examples. Give each element a purpose.
{{< /info >}}

### Choose descriptive headings

A heading is a promise about the next few paragraphs. “Before you publish” tells a reader more than “Additional information.” The contents panel follows the headings on this page.

### Keep related ideas together

Short paragraphs give each idea room to develop. A list works well when several items share the same role:

- Explain the reader's next action.
- Include an example when a concept is abstract.
- Put supporting detail close to the point it supports.

## Give different kinds of information a clear label

Labels help readers recognize useful context, caution, and suggestions. Their meaning stays the same even when the publication uses a different accent color.

{{< notice >}}
An example may need adjustment before it fits your own situation. Read the assumptions before following a procedure.
{{< /notice >}}

{{< important >}}
Keep the original copy of your work before trying a change that cannot easily be reversed.
{{< /important >}}

{{< tips >}}
Read a draft aloud. Places where you stumble often need a shorter sentence or a clearer connection.
{{< /tips >}}

{{< note >}}
A note is a good place for supporting context that readers can return to later.
{{< /note >}}

## Put two related ideas beside each other

{{< columns align="start" >}}
  {{< column >}}
  ### A useful first draft

  Write down the question, your current answer, and the evidence you have. An unfinished but concrete example gives someone else a place to start.
  {{< /column >}}
  {{< column >}}
  ### A useful review

  Ask what is clear, what is missing, and what the reader should do next. Specific feedback is easier to use than a general impression.
  {{< /column >}}
{{< /columns >}}
